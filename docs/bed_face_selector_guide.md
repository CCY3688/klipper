# 床面方向选择功能使用说明

## 功能概述

在执行模型配准之前，用户可以指定 STL 模型的哪个包围盒面应该接触打印床。这样可以将模型正确定向，大大提高配准的成功率和准确性。

## 为什么需要这个功能？

配准算法需要将 STL 模型与扫描点云对齐。如果模型的方向与实际摆放方向不一致（例如，模型的顶面朝下，但实际是底面接触床），配准会失败或产生很大的误差。

通过预先指定床面方向，系统会自动旋转模型到正确的方向，然后再进行配准。

## 使用步骤

### 1. 加载 STL 模型
首先加载你的 STL 模型文件（例如：机翼部分曲面-100.stl）

### 2. 选择床面方向
在"配准结果"卡片中，点击"选择床面方向"按钮（翻转图标 🔄）

### 3. 在对话框中选择方向
对话框会显示：

#### 模型包围盒尺寸
- **X 轴尺寸**：红色标签
- **Y 轴尺寸**：绿色标签
- **Z 轴尺寸**：蓝色标签

这些尺寸帮助你判断模型的方向。

#### 6 个方向选项

| 选项 | 描述 | 含义 |
|------|------|------|
| **+X** | 右侧面接触床 | 模型包围盒的 +X 面朝下 |
| **-X** | 左侧面接触床 | 模型包围盒的 -X 面朝下 |
| **+Y** | 后侧面接触床 | 模型包围盒的 +Y 面朝下 |
| **-Y** | 前侧面接触床 | 模型包围盒的 -Y 面朝下 |
| **+Z** | 顶面接触床 | 模型包围盒的 +Z 面朝下（倒置） |
| **-Z** | 底面接触床 | 模型包围盒的 -Z 面朝下（正常） |

**默认选择**：`-Z`（底面接触床），这是最常见的情况。

### 4. 确认选择
点击"确认"按钮，系统会：
- 应用选择的方向
- 清除之前的配准结果（如果有）
- 在配准卡片中显示当前选择的床面方向

### 5. 加载点云并执行配准
- 加载扫描点云
- 点击"执行配准"按钮
- 系统会自动应用床面对齐变换，然后进行配准

### 6. 查看结果
切换到"配准结果"标签页，可以看到：
- 模型已经按照你选择的方向放置在打印床上
- 模型与点云的对齐情况
- 配准质量指标（RMSE、匹配点数等）

## 选择建议

### 如何判断正确的床面方向？

1. **了解实际摆放**
   - 想象你的实际零件是如何放在打印床上的
   - 哪个面实际接触了床面？

2. **参考包围盒尺寸**
   - 通常接触床面的尺寸是最大的那个面
   - 例如：如果 X=100mm, Y=80mm, Z=20mm
   - 那么 Z 方向可能是高度，-Z 面（底面）接触床

3. **检查 STL 模型方向**
   - 在 STL 模型标签页中查看模型
   - 旋转观察模型的各个面
   - 判断哪个包围盒面对应实际的底面

4. **常见情况**
   - **平面零件**（如机翼、底板）：通常是 `-Z`（底面）或 `+Z`（顶面）
   - **立式零件**（如支架、墙壁）：可能是 `-X`、`+X`、`-Y` 或 `+Y`

## 示例：机翼模型

对于机翼部分曲面-100.stl：

1. **包围盒尺寸**（假设）：
   - X: 120 mm
   - Y: 80 mm
   - Z: 15 mm

2. **分析**：
   - Z 尺寸最小，说明这是高度方向
   - 机翼是平面零件，应该平放在床上
   - 如果 STL 模型的底面是 -Z 方向，选择 **-Z（底面接触床）**
   - 如果 STL 模型被翻转了，选择 **+Z（顶面接触床）**

3. **验证**：
   - 执行配准后，在"配准结果"视图中检查
   - 模型应该平放在打印床上（网格平面）
   - 如果模型方向不对，重新选择并再次配准

## 技术细节

### 变换流程

1. **对齐变换**：
   ```
   alignTransform = bedFaceDirection.getAlignmentTransform(mesh.bounds)
   ```
   将选定的包围盒面旋转到 -Z 方向（床面向上）

2. **应用到模型**：
   ```
   alignedMesh = mesh.transformed(alignTransform)
   ```

3. **配准**：
   ```
   registrationResult = register(alignedMesh, scan)
   ```

4. **合并变换**：
   ```
   finalTransform = registrationTransform * alignTransform
   ```
   最终变换包含了对齐和配准两个步骤

### 坐标系约定

- **机械坐标系**：右手坐标系
  - X 轴：红色（水平，左右）
  - Y 轴：绿色（水平，前后）
  - Z 轴：蓝色（垂直，上下）
  
- **床面**：Z = 0 平面
  
- **床面向上**：法向量为 (0, 0, -1)
  - 即床面的"顶部"指向 -Z 方向

## 故障排除

### 配准后模型方向仍然不对

**原因**：选择的床面方向与实际不符

**解决方法**：
1. 重新选择床面方向
2. 在 STL 模型标签页中旋转观察模型
3. 确认哪个包围盒面对应实际的底面
4. 再次执行配准

### 配准 RMSE 很大（超限）

**可能原因**：
1. 床面方向选择错误
2. STL 模型与实际零件不匹配
3. 扫描点云质量不好

**解决方法**：
1. 首先检查床面方向是否正确
2. 在配准结果视图中观察模型和点云的对齐情况
3. 如果方向明显不对，重新选择床面方向

### 模型在配准结果中看起来倾斜

**正常现象**：即使床面方向正确，模型也可能因为以下原因倾斜：
1. 实际零件放置时有轻微倾斜
2. 打印床不完全水平
3. 配准算法找到的最佳匹配位置

这是正常的，配准算法会找到模型与点云的最佳对齐位置。

## 高级技巧

### 对于复杂形状的零件

如果零件形状复杂，包围盒可能不能很好地代表实际的接触面：

1. **使用预览视图**：
   - 在 STL 模型标签页中观察模型
   - 旋转到接触床面的视角
   - 判断这个方向对应哪个包围盒面

2. **尝试多个方向**：
   - 如果不确定，可以尝试几个候选方向
   - 执行配准并比较 RMSE 值
   - 选择 RMSE 最小的那个方向

3. **参考坐标轴**：
   - 在预览中打开坐标轴显示
   - 红色 X、绿色 Y、蓝色 Z
   - 判断床面法向量应该指向哪个轴

## 总结

床面方向选择功能让你能够：
- ✅ 在配准前正确定向模型
- ✅ 提高配准成功率
- ✅ 减少配准误差
- ✅ 更直观地查看配准结果

**关键步骤**：
1. 加载 STL 模型
2. 点击"选择床面方向"
3. 根据包围盒尺寸和实际情况选择方向
4. 确认并执行配准
5. 在配准结果视图中验证

如有问题，可以随时重新选择床面方向并再次配准。
