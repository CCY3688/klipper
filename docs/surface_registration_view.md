# 曲面配准可视化界面

## 概述

新增的配准结果可视化界面提供了类似 OrcaSlicer 的 3D 视图，可以直观地查看模型在机械坐标系中的位置，而不仅仅是查看变换矩阵的数字。

## 功能特性

### 1. 三个预览标签页

- **STL 模型**：显示原始 STL 模型
- **扫描点云**：显示曲面扫描的点云数据
- **配准结果**（新增）：显示配准后的模型在机械坐标系中的位置

### 2. 配准结果视图内容

#### 打印床 (Bed)
- 150mm × 150mm 的打印床平面（Z = 0）
- 10mm 网格间距
- 半透明灰色，便于观察模型位置

#### 机械坐标轴
- **X 轴**：红色，从原点指向 +X 方向
- **Y 轴**：绿色，从原点指向 +Y 方向
- **Z 轴**：蓝色，从原点指向 +Z 方向
- 轴长：40mm

#### 配准后的模型
- 应用变换矩阵后的 STL 模型
- 光照着色，便于观察表面细节
- 半透明效果，可以看到床和点云

#### 扫描点云
- 根据 Z 高度着色（蓝色→红色）
  - 低点：蓝色
  - 高点：红色
- 每个点都有白色描边，便于识别

#### 状态信息
左上角显示配准结果摘要：
- 状态：通过/超限
- RMSE：均方根误差（mm）
- 匹配点数
- 迭代次数

### 3. 视图控制

#### 显示/隐藏选项（配准结果页面）
- 打印床开关
- 模型开关
- 点云开关
- 坐标轴开关

#### 交互操作
- **旋转**：鼠标左键拖动
- **平移**：鼠标右键/中键拖动
- **缩放**：鼠标滚轮
- **重置视图**：双击画布或点击重置按钮

## 使用流程

1. **加载 STL 模型**
   - 点击"选择 STL 文件"按钮
   - 选择机翼部分曲面-100.stl

2. **加载扫描点云**
   - 点击"读取点云" → "选择历史"
   - 选择 plane_test

3. **执行配准**
   - 点击配准卡片右上角的"执行配准"按钮
   - 等待配准完成

4. **查看配准结果**
   - 配准完成后，自动切换到"配准结果"标签页
   - 可以看到：
     - 模型在打印床上的实际位置
     - 模型相对于机械坐标系的姿态
     - 扫描点云与模型的对齐情况

5. **调整视图**
   - 旋转视图以从不同角度观察
   - 可以隐藏床或点云，专注于模型位置
   - 缩放以查看细节

## 视觉设计

### 配色方案
- 背景：深灰色渐变 (#1E2228 → #2A2F36)
- 打印床：半透明灰色 (#3A3F48, 60% 透明度)
- 网格线：浅灰色 (#4A5160, 80% 透明度)
- 模型：银灰到白色渐变（根据光照）
- 点云：蓝色到红色渐变（根据高度）

### 用户界面风格
- 参考 OrcaSlicer 的深色主题
- 清晰的网格线和坐标轴
- 信息面板采用半透明深色背景

## 技术细节

### 坐标系
- 机械坐标系：右手坐标系
- 原点：(0, 0, 0)
- X 轴：红色（水平）
- Y 轴：绿色（水平）
- Z 轴：蓝色（垂直向上）

### 变换应用
配准结果中的模型位置是通过以下方式计算的：
```dart
transformedPoint = registrationResult.transform.transformPoint(originalPoint)
```

这个变换矩阵将模型从其原始坐标系转换到机械坐标系。

### 渲染优化
- 模型面片采样：最多 4000 个三角形
- 深度排序：使用画家算法（从后到前）
- 光照计算：简单的 Lambert 漫反射

## 示例场景

### 当前示例
- **模型**：机翼部分曲面-100.stl
- **点云**：plane_test
- **配准状态**：超限
- **RMSE**：3.672 mm
- **匹配点**：152

在配准结果视图中，你可以：
1. 看到机翼模型相对于打印床的位置
2. 观察模型的旋转角度（变换矩阵的直观表示）
3. 比较扫描点云与模型表面的对齐情况
4. 理解为什么 RMSE 较大（点云与模型不完全对齐）

## 故障排除

### 配准结果标签页显示"请先执行配准"
- 确保已加载 STL 模型和扫描点云
- 点击配准卡片的"执行配准"按钮

### 模型看起来很小或找不到
- 点击"重置视图"按钮
- 或双击画布自动适配视图

### 模型位置看起来不对
- 检查配准状态是否为"通过"
- RMSE 值较大表示配准质量不佳
- 可能需要检查 STL 模型和实际扫描部件是否一致
