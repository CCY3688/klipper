# 提交代码说明

本目录为关键代码摘取版，仅保留项目自研或强相关代码，未包含完整开源工程、构建产物、固件二进制、图片数据集和历史备份全集。

## 目录内容

- `lib/`：PC 上位机业务代码，包括连接控制、运动控制、书写/雕刻轨迹、曲面标定与补偿、界面状态管理等。
- `01_move/klipper_extras/`：STM32 端 USART2 闭环步进驱动通信代码，以及主机侧电机串口扩展脚本和配置。
- `02_visual/`：视觉标定、误差采样、坐标拟合、曲面轨迹验证等关键脚本和少量最新标定结果。
- `03_extruder/`：点胶/锡膏挤出控制面板及菜单配置。
- `host/`：板端主机相关相机服务、配置备份脚本和实际运行配置摘取。

## 未包含内容

- `build/`、`.dart_tool/` 等生成目录。
- `android/`、`ios/`、`linux/`、`macos/`、`windows/` 等平台模板代码。
- `host/backups` 中的大体量完整第三方项目和固件二进制。
- 实验图片、验证图像、报告素材和历史 G-code 数据。
